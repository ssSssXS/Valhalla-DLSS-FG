# Valhalla DLSS & Frame Generation

Автор мода — **serial humanist**. Открытая бета 0.27 для Steam-версии Assassin’s Creed Valhalla 1.8.0. Режимы доступны в штатном меню игры, ReShade не требуется.

**[Скачать установщик для Windows](https://github.com/ssSssXS/Valhalla-DLSS-FG/releases/tag/v0.27-beta.1)**

1. Закройте игру и запустите **Valhalla-DLSS-FG-Setup-0.27-beta.1.exe**. Установщик сам найдёт игру в библиотеке Steam. Если поле пустое, нажмите **Обзор…** и выберите папку с `ACValhalla.exe`.
2. Нажмите **Установить**. Установщик проверит версию, сохранит исходные файлы и добавит пункт FG в локальный архив меню. Интернет и отдельно установленный Python для установки не нужны.
3. В игре откройте **Настройки → Графика**, выберите режим и нажмите **Применить**.

| Что вы хотите включить | Что выбрать |
| --- | --- |
| DLSS Super Resolution | Тип масштабирования → DLSS, затем «Качество» или «Сбалансированное» |
| DLAA | Тип масштабирования → DLSS, затем DLAA |
| Генерация с DLSS или DLAA | Дополнительно выберите «Генерация кадров DLSS → ×2» |
| Штатное сглаживание + FG | Тип масштабирования → Выкл., масштаб разрешения 100%, штатное сглаживание и «Генерация кадров DLSS → ×2» |

При чистой установке DLSS и FG выключены. Существующие настройки мода сохраняются. В 0.27 проверены RTX 4070 Ti, 3840×2160, переключение DLAA ↔ штатное сглаживание и разговор в «Интерактивном туре» с генерацией ×2. Для сочетания штатного сглаживания и FG проверен масштаб 100%.

**Удаление.** Закройте игру, запустите тот же EXE и нажмите **Восстановить**. Для отката нужна папка `ACVNativeDLSS.Setup` из каталога игры. Если пользователь изменил INI мода после установки, его настройки сохраняются. Сохранения персонажей установщик не меняет.

EXE распространяется без цифровой подписи. Контрольная сумма SHA-256 приложена к релизу. Лицензии доступны из окна установщика и в `ACVNativeDLSS/licenses`.
